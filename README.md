Forecasts Twitch's concurrent viewers in the Grand Theft Auto VI category for hours 2 to 24 of
release day, from the day's first hour alone. The model anchors on the hour-1 print and applies
log-space shape offsets learned from comparable launch curves in the case's own history, with a
spread that widens with the horizon. Deterministic, stdlib only, no network.

## Run it

```sh
MAKEFUN_INPUT_DIR=<case dir> MAKEFUN_OUTPUT_DIR=<out dir> python3 -P -s main.py
```
